AFPSS WEBSITE — GitHub Pages

या फोल्डरमध्ये:
- index.html = मुख्य वेबसाइट
- CNAME = afpss.org.in
- assets/ = तुमचे फोटो

GitHub वर अपलोड:
1. Repository उघडा.
2. Add file → Upload files.
3. या ZIP मधील index.html, CNAME आणि assets फोल्डरमधील सर्व फोटो अपलोड करा.
4. Commit changes करा.
5. GitHub → Settings → Pages मध्ये Deploy from branch → main / root निवडा.
6. Custom domain मध्ये afpss.org.in ठेवा (CNAME आधीच तयार आहे).

महत्त्वाचे: index.html आणि assets फोल्डर एकाच repository च्या root मध्ये असणे आवश्यक आहे.
